# Sorry, I Heard That Wrong

A one-line apology a smart speaker gives its owner after mishearing them.
Entry for the make.fun micro-copywriting competition
[u-kiencx-sorry-i-heard-that-wrong-1858c729](https://make.fun/bounty/u-kiencx-sorry-i-heard-that-wrong-1858c729).

## Run

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` writes a single line (<= 140 chars) to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`). Stdlib only.
